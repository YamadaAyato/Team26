# Yamamoto 個人作業領域の開発指示

## 適用範囲

この指示は `Assets/Personal/Yamamoto/` 以下の開発に適用する。

## 作業前に確認する資料

まず `Docs/DevelopmentReferences.md` を読み、以下のNotion資料の必要な原文を確認する。

1. 企画・仕様書・タスク: https://app.notion.com/p/3fed9a299e3a80be95afeeaa6b7f484c
2. Unity / C# 共通コード規約: https://app.notion.com/p/Unity-C-by-410d9a299e3a8076a03bfa8b954dfb63

## 実装・確認の原則

- 企画ページから現行の仕様書、対象システムの子ページ、該当タスクを確認し、担当範囲・接続先・完了条件を把握してから実装する。
- 仕様書は現行版を優先する。ボツ保管庫の旧仕様や過去の検討メモを実装根拠にしない。
- 確定仕様・仮値・発展機能を区別し、未確定事項を独断で確定仕様にしない。
- Unity / C# 共通コード規約を遵守する。プロジェクト固有の規約がある場合はそちらを優先する。
- 対象ファイル、呼び出し元、依存先、同種の既存実装を確認し、依頼と無関係な変更や他担当領域の無断変更を行わない。
- Notionにアクセスできない場合は、対象ページと確認できなかった範囲を報告する。内容を推測で補完せず、未確認の内容に依存する実装判断は保留する。
- 確認できなかった事項を確認済みと報告しない。コード変更後は共通規約に従って変更・検証・未確認事項を報告し、人間によるレビューを依頼する。
